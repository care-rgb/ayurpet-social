# Prompts for Claude

Open Claude Code in this folder and paste these. Claude reads `CLAUDE.md` here, so it already knows the setup.

## Monday: pull and decode

```
Run the weekly outlier pull and our scorecard. Then open this week's outlier list and, for the top 10 across both markets, watch-decode each one from its caption and stats: hook, format, emotion, who would send it to whom, and our version with AyurPet dogs. Group them into patterns (same hook or format showing up more than once). Write it into the outlier .md file under each post, then give me the 3 strongest patterns in plain words.
```

If Claude can't watch a reel, open the link yourself, watch it, and say what happens in the first 3 seconds. Claude will fill in the rest.

## Monday: what worked for us

```
Read this week's scorecard. Which of our posts won and which flopped, and why, compared with our normal? Tag any untagged posts in ledger/tags.csv (ask me what format and hook they were if you can't tell from the caption). Add winners to ledger/WINNERS.md and anything new we learned to ledger/LEARNINGS.md. Keep it short.
```

## Tuesday: plan the week

```
Plan this week's posts for both pages: about 5 reels and 2 carousels a page. Mix: half are new versions of our winners in ledger/WINNERS.md, 4 in 10 copy the mechanism of a 5x+ outlier from this week's list (with our own dogs and footage, never a repost), the rest are bold new tests. For each post write a brief in briefs/ using briefs/TEMPLATE.md. India posts look Indian. Make every hook something a dog parent would send to a friend.
```

## Any day: one post from one outlier

```
Here's a reel that's blowing up: <link>. What happens is: <describe the first 3 seconds and the payoff>. Write 3 versions we could make for @ayurpetofficial / @ayurpet_global with our own dogs: hook line, on-screen text, shot list, length, caption under 60 words, and who would send it to whom.
```

## Any day: hooks

```
Give me 15 hooks for a reel about <topic> for <India / global> dog parents. Under 8 words each, dog in the first frame, mix of POV, "your dog does this because", myth-busting and day 1 vs day 30. Mark the 3 you'd bet on.
```

## Find more pages to study

```
Find 10 more Instagram pages (business or creator accounts) whose dog reels regularly go viral in <India / US / UAE>, that aren't in watchlist.csv. Add them with market, lane and a short note, then run outliers.py --check and remove any that can't be read.
```
